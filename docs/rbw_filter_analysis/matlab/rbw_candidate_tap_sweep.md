## Engineering Notes

- `accum_target = observe + skip + taps`.
- `first_valid = taps - 1 + skip`.
- `out_len = accum_target - first_valid`, which equals `observe + 1` with this windowing model.
- 1 kHz `alias_rework_1k` uses `R=1300`, so `Fs_out=100 kHz`, sample period is 10 us, and the same sample count covers one tenth of the old `R=13000` time span. It avoids the 10 kHz/10.2 kHz passband-folding geometry, but increases post-CIC sample rate and FIR work per second by 10x before tap-count changes.
